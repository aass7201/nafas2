# 🧠 بوت Nafas2 - قسم علم النفس (المرحلة الثانية)

بوت تلغرام متكامل مخصص لخدمة طلبة قسم علم النفس (المرحلة الثانية)، مبني باستخدام لغة **Python** وأحدث إصدار من مكتبة **python-telegram-bot (v20+ Async)** وقواعد بيانات **PostgreSQL** (via Supabase/Neon).

---

## 📋 المميزات والخصائص

### 1. واجهة الطالب (User Interface):
- **الترحيب التفاعلي والتسجيل التلقائي:** عند إرسال `/start`، يتم تسجيل بيانات الطالب في قاعدة البيانات وترحيب أنيق باسمه.
- **القائمة الرئيسية (Reply Keyboard):**
  - 📚 **الكتب والمناهج:** اختيار المادة وعرض/تحميل كتبها مباشرة.
  - 📄 **الملخصات والملازم:** استعراض الملازم والمحاضرات بصيغة PDF.
  - 📝 **الأسئلة الامتحانية:** استعراض نماذج الأسئلة الشهرية والنهائية (ملفات وصور).
  - 📢 **التبليغات والجدول:** استعراض أحدث تبليغ رسمي أو جدول امتحانات نشره الأدمن.
  - ℹ️ **حول البوت:** نبذة تعريفية بالبوت وأهدافه.
- **🧠 الدعم النفسي والتدريب السريري:**
  - اختبار نفسي سريع (4 أسئلة) مع تصنيف الفئة
  - مرشد نفسي ذكي (دردشة باللهجة العراقية)
  - المشرف الأكاديمي الذكي (نقاش حالات سريرية)
  - الممارسة السريرية التفاعلية (محاكاة مرضى ديناميكية)
  - تدريب عملي بأسلوب سقراطي (Roleplay Evaluator)

### 2. لوحة تحكم الأدمن (Admin Panel):
- يتم الدخول إليها عبر أمر `/admin` (محمية بمعرف الأدمن `ADMIN_ID`).
- **لوحة تفاعلية بأزرار Inline Keyboard:**
  - 📊 **الإحصائيات العامة:** عرض عدد الطلاب المسجلين، إجمالي الملفات، وتوزيع الملفات حسب كل مادة وقسم.
  - 📤 **رفع محتوى جديد:** خطوة بخطوة (اختيار القسم ⬅️ اختيار المادة ⬅️ إرسال الملف أو الصورة) مع إمكانية رفع عدة ملفات متتالية بنفس المادة أو الإلغاء في أي وقت.
  - 📢 **إذاعة عامة (Broadcast):** إرسال أي رسالة أو وسائط (نص، صورة، ملف، صوت، تحويل) لجميع الطلاب المسجلين مع تقرير بعدد المستلمين الفعلي ومن قام بحظر البوت.
  - 🗓️ **تحديث التبليغات والجدول:** تعديل نص التبليغ أو الجدول ليظهر مباشرة للطلاب.
  - 🗑️ **إدارة وحذف الملفات:** تصفح الملفات حسب المادة وحذف أي ملف مباشرة بنقرة زر واحدة.
  - 🔑 **ضبط مفتاح Gemini API:** تحديث مفتاح الذكاء الاصطناعي من لوحة التحكم.
  - 🤖 **إدارة توجيهات الذكاء الاصطناعي:** تعديل شخصية كل نموذج (المرشد، المشرف، مدرب التدريب).

## 🛠️ متطلبات التشغيل والتثبيت

1. تثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```

2. إعداد ملف `.env` أو متغيرات البيئة:
   ```
   BOT_TOKEN=توكن_البوت
   ADMIN_ID=رقم_المعرف
   GEMINI_API_KEY=مفتاح_Gemini
   DATABASE_URL=رابط_قاعدة_البيانات
   ```

3. تشغيل البوت:
   ```bash
   python bot.py
   ```

## 🔍 فحص حالة البوت (check_proc.py)

أداة لمراقبة وتحقق من حالة عملية البوت:

```bash
# فحص سريع للحالة
python check_proc.py

# فحص قاعدة البيانات فقط
python check_proc.py db

# فحص Telegram API
python check_proc.py telegram

# فحص Gemini API
python check_proc.py gemini

# إعادة تشغيل البوت
python check_proc.py restart

# مراقبة مستمرة (كل 30 ثانية)
python check_proc.py monitor 30

# عرض آخر حالة محفوظة
python check_proc.py status
```

## 🗄️ قاعدة البيانات (PostgreSQL)

يتم إنشاء الجداول تلقائياً عند التشغيل الأول عبر `DatabaseManager.init_db()`:
- **`users`:** لحفظ الطلاب المسجلين ومعرفاتهم وتاريخ الانضمام.
- **`files`:** لتخزين `file_id`، اسم الملف، المادة الدراسية، ونوع الملف (كتاب، ملخص، أسئلة).
- **`announcements`:** لتخزين التبليغات والجداول المحدثة.
- **`bot_settings`:** لإعدادات البوت (مفاتيح API، توجيهات الذكاء الاصطناعي).
- **`psychological_assessments`:** لنتائج الاختبارات النفسية للطلاب.
